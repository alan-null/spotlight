# Spotlight Theme Studio

Open the [theme studio](./index.html) from the [Spotlight site](../index.html). No build step or application dependencies are required. For a local HTTP preview, run `python3 -m http.server 8765 --directory docs` from the repository root and visit `http://localhost:8765/theme-studio/`. The page's Light/Dark switch changes site appearance; the selected theme preset and color controls change the terminal theme you export.

Use the **Choose color** control beside every color to open your browser’s visual color picker; no hex codes are needed. Color code inputs remain available for hex, ANSI indices, and terminal defaults. Edit all 11 interface colors and 10 built-in category colors, or add custom categories. Start from Spotlight dark or light, original, terminal ANSI, Monokai, dusk, or paper presets. Changes are saved in browser storage when available. The Commands scene includes every built-in category, a Docker-prefixed category, and an unmapped category that falls back to accent. Use the Parameters, Errors, and Settings scenes to inspect breadcrumbs, installation errors, and setting values. Search highlights matches; clicking a sample row updates its preview. All commands are inert fixtures.

Download or copy the generated TOML, save it to `$XDG_CONFIG_HOME/spotlight/themes/NAME.toml` (default `~/.config/spotlight/themes/NAME.toml`), then choose **Settings → Theme → NAME** in Spotlight. Theme names must start with a lowercase letter and contain only lowercase letters, digits, underscores, or hyphens. Downloads include every resolved color, including inherited defaults.

Import supports Spotlight's flat `[colors]` and `[categories]` tables, bare or quoted keys, single-line single- or double-quoted color strings, and comments. Unsupported TOML syntax and invalid values report an error without replacing the current theme. Missing entries inherit the original Spotlight defaults.

The preview follows the color roles in [spotlight_config.py](../../lib/spotlight_config.py) and the tab, row, action-preview, and error styling in [spotlight](../../bin/spotlight) and [settings.sh](../../lib/settings.sh). It approximates fzf layout rather than emulating a terminal. The expandable terminal palette controls let you match ANSI slots 0–15 and default foreground/background to your terminal; these browser-only settings are excluded from exported themes. Slots 16–255 use the standard xterm cube and grayscale ramp. Actual shades, fonts, and selection rendering depend on your terminal and fzf version.

## Monokai and ready-to-use colors

The Monokai preset ports [VS Code’s Monokai theme](https://github.com/microsoft/vscode/blob/main/extensions/theme-monokai/themes/monokai-color-theme.json), using its editor background/foreground, quick-input selection, syntax green accent/command text, and syntax colors for category labels. The same mapping ships as [monokai.toml](../../themes/monokai.toml), available through Spotlight’s **Settings → Theme → monokai**. It is an additional built-in choice; the original default is preserved.

The **Ready-to-use colors** library includes 53 distinct RGB swatches extracted from the source theme, including 39 colors unused by the initial Spotlight mapping. Select an interface role or category under **Apply to**, then click a swatch. **Unused only** filters against the colors currently assigned in your theme. Add a category with **+ Add category**, select it as the target, and apply any library color. This library stays available with every preset and imported theme. **Current theme** provides reusable swatches from your current assignments. These colors are suggestions, not a restriction on the visual picker or manual inputs.

[palettes.js](./palettes.js) stores the offline Monokai mapping, full extracted library, original source roles and values, source URL, and a SHA-256 of the fetched source. Eight-digit RGBA colors are composited over Monokai’s `#272822` editor background and labeled “blended”, since Spotlight only accepts opaque RGB colors. Editor metadata is kept outside the theme TOML so the runtime’s existing schema remains valid. Exported TOML contains the colors actually assigned to roles and categories; the complete library remains in the editor. Source colors are from Microsoft’s MIT-licensed VS Code theme; see [MONOKAI-LICENSE.txt](./MONOKAI-LICENSE.txt).
